# Titan — AI Context Entry Point

Start here when an AI agent is asked to modify this repository.

1. Read `docs/ai/QUICK_CONTEXT.md`.
2. Read `docs/ai/MODULE_MAP.md`.
3. Read `docs/ai/CONTRACTS.md`.
4. Read `docs/ARCHITECTURE.md`.
5. Read only the domain/UI module relevant to the requested change.
6. Run `npm run check` after code changes.
7. Run `npm run build` before considering a UI/application change complete.

## Non-negotiable
Do not silently change gameplay behavior. Preserve existing terminology and rule comments. If a rule is unclear, document the ambiguity instead of inventing a new rule.
