# Contributing

1. Une règle de gameplay doit être modifiée dans `src/domain/` uniquement.
2. Aucun gameplay dans les composants UI.
3. Aucun React/DOM/Three.js dans l'IA.
4. Toute nouvelle règle doit recevoir un test.
5. Exécuter `npm run audit`, `npm test`, `npm run lint` et `npm run build` avant une PR.
